📝 CSV Format Requirements

The CSV file must contain these columns:

  • itemname: Name of the menu item
  • available_timings: Time ranges (HH:MM-HH:MM) separated by commas. Supports ranges spanning midnight (e.g., "22:00-02:00")
  • exclude_dates: Dates to exclude (DD-MM-YYYY format, comma-separated). Leave empty "" if none
  • exclude_days: Weekdays to exclude (e.g., "Monday, Friday"). Leave empty "" if none

Example:

itemname,available_timings,exclude_dates,exclude_days
Dosa,"16:00-21:00,07:00-10:00,10:45-12:00","20-03-2024, 25-03-2024","Monday, Friday"
